# Titan icons

28 PNG portraits, named using English Hero Wars: Alliance titan names.
Created with built-in imagegen in reference-image editing mode from the four supplied screenshots. These are generated edits, not pixel-exact crops. The gray level plaques are blank; Tenebris retains the locked appearance without a level plaque.

## Prompt template

Extract only {name}, row {row} column {column}, into one square PNG game portrait icon. Remove white level digits, leaving gray plaque blank. Preserve original face, colors, silver frame and bottom stars. No other UI or text. Plain dark brown outside icon, no checkerboard. Keep original artwork faithfully.

Later prompts specify the exact star count or one blue star with gold wings. Tenebris uses: “Preserve the dark locked silhouette exactly, do not invent colored portrait, no stars or level plaque.”
